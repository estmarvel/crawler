爬虫代码按执行阶段分为三部分：

1. 网站分析（探索API）

explore_site.py — 探索网站结构
find_api.py / test_api.py — 测试API接口
analyze_list_api.py / test_list_params.py — 分析列表API参数
verify_data.py — 验证数据完整性
2. 数据爬取（核心）

crawler.py — 初版测试爬虫（100条）
crawler_full.py — 完整爬虫，爬取全部5526条数据
3. 字段解析（21字段提取）

extract_final.py — 最终版解析脚本，从HTML中提取21个指定字段
extract_21fields_v2~v6.py — 迭代优化版本
analyze_format.py — 分析正文HTML格式
最关键的两个文件是：

爬取数据: crawler_full.py
提取字段: extract_final.py
