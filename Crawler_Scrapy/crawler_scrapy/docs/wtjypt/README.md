# 伟拓招标采购交易平台（招标项目）

站点代码直接调用公开前端使用的 JSON 接口，不使用 Selenium。

采集范围仅包含招标项目的 4 个栏目，全部使用网站前端的“全部”分类：

- 招标项目：招标计划、招标公告、评标结果、中标结果。

工程、货物、服务不拆分请求；每条公告的具体分类仍从伟拓详情接口的
`tenderNature`、`classificationName` 保存到统一字段中。

其中招标公告栏目内的变更、延期、终止、撤销、废标、流标和补充公告会动态映射为更正结果公示，并单独输出，避免与普通公告字段混写。

字段抽取优先使用详情接口的结构化字段，再按伟拓正文中的固定标题补齐精确开标时间、递交截止时间、保证金、中标单位/金额及招标人与代理机构联系方式。主体地址只在各自联系方式区块内提取，不使用项目地点补填招标人地址。

手动小批量运行：

```bash
cd /home/intsig/Crawler_Scrapy
START_DATE=2026-08-01 END_DATE=$(date +%F) MAX_RECORDS=1 bash run_wtjypt.sh
```

结果位于 `output/wtjypt/`。脚本不会创建 cron 或定时任务。
