# 太原市公共资源交易中心

本实现依据站点 2026-02-03 构建的全部入口前端分包核对接口和栏目，不使用 Selenium。

采集范围为工程建设、综合交易类，各包含：招标公告、澄清修改、控制价公示、中标候选人、中标结果公示、合同公示、其他公告、项目经理（总监）变更，共 16 个分支。

前端公开接口：`/apiJyxx/list`、`/apiJyxxDetail/list`、`/apiJyxxDetail/gcjsGGDetail`。请求同时复现前端 `hashSign` 参数和 `sign` 请求头。HTML 快照由详情接口返回的原始公告 HTML 加标题、发布日期组成；原始接口 JSON 另存 payload 供核验。

字段规则同时兼容本站的 14 位发布时间、`工程编码`、澄清后的新开标时间、`公示日期`、代理机构`项目负责人`，以及“招 标 人 / 联 系 人”等带空格标签。招标项目地址不会映射为招标人地址；正文未提供的地址、行业、工期等字段保持为空。

```bash
START_DATE=2020-01-01 END_DATE=$(date +%F) MAX_RECORDS=1 bash run_tyggzy.sh
```
