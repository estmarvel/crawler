# 山西新点字段来源说明

## 页面与接口

- 首页与栏目页用于确认“招标信息”“企业采购”的栏目、分类及页面参数。
- 招标信息列表调用 `searchlistAction_Custom.action?cmd=getSerachlist`，使用 `cate2` 区分公告栏目、`cate3` 区分工程/货物/服务。
- 企业采购列表调用 `searchlistAction_Custom.action?cmd=getSerachgglxlist`，使用 `cate2` 区分公告栏目；采购方式最终以详情标题和正文为准。
- 两个列表接口返回外层 JSON，`custom` 字段内仍是一段 JSON 字符串；爬虫二次解码后读取 `Table`、`RowCount`、`title`、`date`、`href`。
- 详情页面是服务端渲染 HTML：标题来自 `.ewb-info-tt`，正文来自 `.ewb-article`，附件来自正文中的文件链接。

## 公共字段

- 公告标题、发布日期、详情链接：列表记录与详情页标题组合解析。
- 项目名称：优先读取正文的“项目名称”，不存在时去除标题中的公告类型后缀。
- 项目编号/招标编号、采购编号：读取“项目编号”“招标编号”“采购编号”等站点原文标签。
- 组织形式、招标方式、项目类型/行业分类：正文对应标签；招标信息的工程/货物/服务同时由列表 `cate3` 确认。
- 招标人/采购人及代理机构：从正文“招标人/采购人”“招标代理机构/采购代理机构”及各自地址、联系人、电话分段解析。
- 附件：解析 `.ewb-article` 内指向 pdf、doc、docx、xls、xlsx、zip、rar 等文件的链接并交给统一附件下载流程。

## 招标计划

- 投资项目统一代码、项目名称、项目类型、投资估算/项目总投资、招标内容、招标方式、招标人、行政监督部门、发布单位、建设地点、建设内容及规模、预计发布时间：均从详情正文同名或近义字段提取。

## 招标公告与资格预审公告

- 项目概况、资金来源、项目地点、招标内容与范围、工期/供货期/服务期限、质量要求、投标人资格、文件获取时间与方式、递交截止时间与地点、开标时间与方式、评审办法、投标保证方式：从详情正文的编号章节和字段标签提取。
- 企业采购公告还会提取采购范围、预算金额/最高限价、采购需求、合同履行期限等采购语义，并映射到统一招标公告字段。

## 中标候选人公示

- 公示时间、项目编号、候选人名称、候选人排序、候选人明细、项目负责人、业绩、质量、工期/交货期、评标情况、异议渠道：优先解析详情中的 HTML 表格，再结合正文标签补全。

## 结果公告

- 中标/成交单位、中标金额、中标明细、项目负责人、评标委员会、采购内容、联系人：从结果正文和 HTML 表格解析；企业采购“成交结果”也映射到统一中标结果字段。

## 变更、其他、终止及废标公告

- 公告标题中含变更、更正、终止、废标、流标时，解析原公告时间、变更公告时间、变更前后内容、原因、影响范围及联系人。
- 网站“其他公告”栏目会混放招标公告、询比采购公告、资格预审、候选人、结果、合同、流标和终止公告；解析器会同时检查详情标题与正文开头动态选择统一Schema，并在输出文件名中追加实际公告类型，避免不同字段结构混写。

## 合同公示

- 合同编号、合同名称、项目编号、采购人、供应商、合同金额、签订日期、履约期限、地点和采购方式：从企业采购合同公示正文的同名字段提取。
