# 吕梁市公共资源交易中心

采集范围来自交易服务页前端展示的 8 个交易大类、60 个叶子栏目：工程建设、水利工程、交通运输、产权交易、电力工程（能源）、土矿交易、农业工程、其他工程。

该站使用静态 CMS 列表与详情页。绝大多数详情正文嵌在 PDF iframe 中，因此 Spider 会继续请求 PDF 并通过 `pypdf` 提取正文，再按公告类型写入统一字段。HTML 快照内同时保存详情页原始源码和 PDF 提取文本；PDF 作为附件下载，列表信息作为原始 payload 留档。

实跑发现合同公开中存在约 80MB 的 PDF，下载超时已按本站调高到 300 秒。少量历史产权、合同、废标 PDF 只有扫描图像而没有文字层；代码会保留原 PDF、记录 `llggzy/pdf_text_layer_empty` 统计并打印警告，不会凭空编造字段。若服务器另行部署 OCR，可再对这些附件进行二次识别。

站点规则覆盖 PDF 表格转文本后的中标候选人/报价、中标人/中标价，招标计划的十三项编号标签，澄清延期后的最终开标时间，合同签署句式，以及招标人、代理机构、监督部门的联系信息。

官网“其他工程”的“招标公告”按钮错误指向 `/zbgg/`（该地址实际页面标题为“中标结果公示”）。实现改从“其他工程-全部”页筛选带 `[招标公告]` 前缀的记录，避免类型错标。
