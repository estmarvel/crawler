# 真实数据库接入前后端修改说明

> **已归并（2026-07-27）：** 本文是首次真实数据接入的逐文件变更记录，包含当时任务 ID、数量、异常类型数和构建结果，不是当前动态状态。仍有效的文件修改原因、前端规则、服务器配置和数据库结构已合并到《数据库修改与接口变更汇总说明》。

## 1. 修改目标与边界

本轮修改的目标是让项目运行时读取 MySQL 的 `crawler` 数据库，并让《管理端展示内容与数据库字段 对接说明》中指定的管理概览、采集中心、异常处理、项目池页面显示真实数据。

前端处理原则：

- 保留原页面布局、卡片数量、表格结构、按钮区域和样式。
- 只在页面脚本中调用 API，并把真实返回值转换为原页面已经使用的字段格式。
- 不再通过随机数、定时伪造日志或静态 mock 填充上述页面。
- 启动采集、停止、重试、定时任务和异常处置接口均已接入原管理端按钮；页面布局与样式保持不变，操作结果来自真实接口，不再伪造成功结果。

前一阶段完成真实数据展示；本阶段继续实现受控运行、日志、调度和异常处理，并将这些接口接入管理端原有按钮。页面主体布局、漏斗、趋势和表格视觉结构保持不变。

爬虫操作按钮现已接入：

- `CollectionCenter.vue`：采集、快速重试、再次执行、停止；新建单次任务时可选择增量、指定日期范围或全历史，以及立即/预约执行；定时计划在独立区域新建、编辑、暂停和启用；运行任务自动连接 SSE 实时日志。

- `ExceptionHandle.vue`：改用持久化 `crawl_exception`；支持重试、忽略和标记已解决，展示真实重试次数、处理人和备注。

说明：标签字典、质量评分、人工审核、用户权限等不在《管理端展示内容与数据库字段 对接说明》指定的四个爬虫数据页面范围内，仍维持原状态，本轮没有把这些业务扩展为真实接口。

采集中心的漏斗图已按原版恢复：阶段顺序、阶段名称、六组渐变颜色、边框、标签、Tooltip 和趋势图面积填充均保持原配置；只有各阶段数值来自真实数据库。由于当前 `CrawlTask.totalCount`、`RawNotice` 和 `NoticeExtraction` 都是 3844，前三段在真实图中宽度相同，这是数据结果，不是样式变化。

接口复核时修正了以下口径：

- MySQL `DATETIME` 返回时保持数据库原始年月日时分秒，避免重复增加 8 小时。
- 异常列表和异常统计不再受 200 条截断影响。
- 数据源和采集中心成功率按所有相关 `CrawlTask` 聚合，不再只统计最近 20/100 条任务。
- `ProjectNotice.crawlTime` 返回完整日期时间，`publishDate` 保持日期格式。
