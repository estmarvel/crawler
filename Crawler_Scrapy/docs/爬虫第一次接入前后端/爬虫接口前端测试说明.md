# 爬虫接口前端测试说明

> **已过时（2026-07-27）：** 本文中采集任务重试确认框、按钮文字和部分页面说明已与当前前端不同。当前前端操作规则、服务器地址和出口模式已合并到《数据库修改与接口变更汇总说明》；真实任务入库验收请使用《前端采集数据数据库验证说明》。

## 1. 启动

API 必须重新构建并启动：

```bash
cd /home/intsig/ProjectRecommendationSystem/api
npm run build
npm start
```

管理端静态构建：

```bash
cd /home/intsig/ProjectRecommendationSystem
npx vite build --config vite.admin.config.ts
serve -s dist-admin -l 8802 --no-clipboard
```

访问 `http://<服务器地址>:8802/#/collection`。通过 SSH 端口转发访问时，可使用 `http://localhost:8802/#/collection`。

## 2. 采集中心

- “采集”：打开完整任务表单，可选数据源、任务类型、栏目、限制、超时和预约时间。
- “重试”：确认后按最近 1 天、全部四个栏目创建增量任务。
- “停止”：只在存在 `PENDING`、`RUNNING`、`CANCEL_REQUESTED` 任务时可用。
- 实时日志：运行任务存在时自动连接 SSE；任务结束后恢复数据库任务摘要。
- “新建任务”：在下方定时任务区域创建固定间隔计划。
- 定时任务“编辑/暂停/启用”：直接更新 `crawl_schedule`。

## 3. 数据来源

- “同步”：创建最近 1 天全部栏目的增量任务。
- “测试连接”：创建单栏目、单页、最多 1 条的真实任务。
- 同一数据源存在活动任务时按钮禁用。

## 4. 异常处理

- 列表读取 `crawl_exception`，而不是静态 mock。
- “重试”：复制原任务配置并创建新任务。
- “忽略”：将异常状态改为 `IGNORED`。
- 详情中的“标记已解决”：将状态改为 `RESOLVED`。

## 5. 服务器直连与备用代理

当前使用服务器公网 IP：

```dotenv
CRAWLER_OUTBOUND_MODE="direct"
```

直连模式使用单并发、5 秒随机延迟、AutoThrottle 和 403/429 自动关停。管理端“新建采集任务”的分页、每栏目数量、最大页数和超时均为可选；未填写时采集完整时间范围，并继续受直连安全预算保护。快捷同步和连接测试仍会显式提交各自的小范围参数。

如果固定代理账号已经失效，可以复用爬虫现有的天启动态代理模式：

```dotenv
CRAWLER_OUTBOUND_MODE="tianqi"
TIANQI_SECRET="实际密钥"
TIANQI_SIGN="实际签名"
```

`direct`、`static`、`tianqi` 的出口逻辑都在 `Crawler_Scrapy` 中实现，API 负责传递部署环境、校验并使用任务实际提交的运行参数，以及启动统一脚本。
